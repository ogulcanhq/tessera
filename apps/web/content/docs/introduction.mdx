Tessera is a free, open-source collection of SwiftUI components for iOS 17 and later. Each component is written once, in the `Sources/` folder of the repository, and reaches you in three ways:

- **Swift Package.** Add Tessera with Swift Package Manager and `import Tessera`.
- **Copy the source.** Every component page shows the exact files from the repository. Paste them into your app and change whatever you like.
- **Showcase app.** A native app in the repository that lets you try every component on a simulator or device.

## Components and features

A **component** is one reusable piece of UI, such as a button or a progress indicator. It keeps only local state and takes its text and data from you.

A **feature** is a complete flow, such as onboarding or a settings screen, assembled from components. Features are planned but not yet available.

## Previews you can trust

SwiftUI can’t run in a web browser, so the previews on this site are recordings of the real component, captured from the Showcase app in the iOS Simulator. Each preview says which device and iOS version it was recorded on.

## Status

Tessera hasn’t had its first release yet. The first component, [Animated Button](/components/animated-button), is available in beta from the `main` branch.
